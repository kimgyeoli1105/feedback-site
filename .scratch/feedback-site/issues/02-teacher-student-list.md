# 02: 선생님 학생 목록과 제출 상태 확인

**What to build:** 선생님이 학생 목록에서 학생 이름, 제출 상태, 확인하지 않은 글 수를 확인할 수 있는 흐름을 만든다.

**Blocked by:** 01: 학생 답변 제출

**Status:** ready-for-agent

- [ ] 브라우저에서 학생 목록이 보인다.
- [ ] 목록에 학생 이름이 보인다.
- [ ] 각 학생에게 미제출, 제출 완료, 피드백 완료, 수정 제출 중 하나의 상태가 보인다.
- [ ] 확인하지 않은 글 수가 화면에 보인다.
- [ ] 학생 답변 제출 후 목록의 해당 학생 상태가 제출 완료로 바뀐다.
