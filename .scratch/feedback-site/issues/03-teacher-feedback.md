# 03: 선생님 학생 글 확인과 피드백 저장

**What to build:** 선생님이 학생을 선택해 제출 글을 읽고, 2~3문장 피드백과 격려 문구를 저장할 수 있는 흐름을 만든다.

**Blocked by:** 02: 선생님 학생 목록과 제출 상태 확인

**Status:** ready-for-agent

- [ ] 학생 목록에서 학생을 선택하면 학생 이름과 제출 글이 보인다.
- [ ] 제출 시간이 화면에 보인다.
- [ ] 2~3문장 피드백 입력 칸과 격려 문구 입력 칸이 보인다.
- [ ] 피드백과 격려 문구를 저장하면 피드백 완료 상태가 보인다.
- [ ] 학생의 최초 제출 글과 수정 글을 구분해서 확인할 수 있다.
