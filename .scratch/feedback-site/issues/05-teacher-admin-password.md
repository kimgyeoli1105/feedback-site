# 05: 선생님 화면 관리자 비밀번호 보호

**What to build:** 선생님 화면을 열기 전에 관리자 비밀번호를 입력하게 하고, 올바른 비밀번호를 입력한 경우에만 학생 목록과 선생님 전용 내용을 확인할 수 있게 한다.

**Blocked by:** 04: 학생 피드백 확인과 수정 제출

**Status:** ready-for-agent

- [ ] 브라우저에서 선생님 화면을 선택하면 관리자 비밀번호 입력 화면이 보인다.
- [ ] 관리자 비밀번호를 입력하기 전에는 학생 글, 학생 목록, 선생님 전용 내용이 보이지 않는다.
- [ ] 잘못된 비밀번호를 입력하면 안내 문구가 보이고 선생님 화면이 열리지 않는다.
- [ ] `teacher-demo`를 입력하면 선생님 학생 목록이 보인다.
- [ ] 올바른 비밀번호를 입력한 뒤에만 학생 목록과 선생님 전용 내용을 확인할 수 있다.
- [ ] 학생 화면은 관리자 비밀번호를 입력하지 않아도 열리고 학생 답변 제출 화면이 보인다.
