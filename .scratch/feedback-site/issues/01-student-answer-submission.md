# 01: 학생 답변 제출

**What to build:** 학생이 수업 제목과 오늘의 질문을 보고 3~10문장으로 답변을 제출한 뒤 제출 상태를 확인할 수 있는 흐름을 만든다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 브라우저에서 수업 제목과 오늘의 질문이 보인다.
- [x] 학생이 3~10문장 답변을 입력하고 제출할 수 있다.
- [ ] 제출 후 제출 완료 상태가 화면에 보인다.
- [ ] 브라우저를 새로고침해도 제출 글과 제출 상태가 유지된다.
